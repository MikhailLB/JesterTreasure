GAME IDEA Игра: Jester Treasure

Общее описание

Jester Treasure — простая гиперказуальная мобильная игра с управлением
одним пальцем. Игрок управляет веселым придворным шутом, который
охраняет королевское хранилище с сокровищами. Жадные монстры пытаются
украсть золото, а задача игрока — остановить их.

Основная цель

Не позволить врагам добраться до сокровищницы. За каждого побежденного
врага игрок получает золотые монеты, увеличивает счет и постепенно
заряжает суперспособность.

Игровой процесс

Главный герой находится в центре игрового поля рядом с огромным сундуком
с сокровищами.

Враги появляются с разных сторон и постепенно приближаются к хранилищу.

Игрок нажимает на экран, проводит пальцем, чтобы выбрать направление
броска, и отпускает палец.

После отпускания пальца Шут бросает зачарованную золотую монету.

Если монета попадает во врага, тот исчезает, а игрок получает Treasure
Coin.

Основная механика

• Управление одним пальцем. • Drag to Aim. • Release to Throw. • Простые
правила без обучения. • Яркие эффекты при каждом попадании.

Враги

Gold Goblin Быстрый гоблин, который пытается украсть золото.

Treasure Mimic Живой сундук. Медленнее гоблина, но выдерживает больше
попаданий.

Рост сложности

По мере игры: - увеличивается количество врагов; - возрастает скорость
их движения; - одновременно появляются разные типы противников; - игроку
приходится быстрее реагировать.

Система наград

За каждого побежденного врага начисляются Treasure Coins.

Монеты увеличивают общий счет и заполняют шкалу Treasure Burst.

Treasure Burst

После заполнения шкалы игрок может активировать суперспособность.

Во время активации: - происходит мощный взрыв сокровищ; - экран
заполняется золотыми монетами, драгоценными камнями и магическими
искрами; - все враги уничтожаются; - игрок получает большое количество
бонусных очков.

Визуальный стиль

Яркая мультяшная графика в стиле casual mobile.

Основные элементы: - золотые монеты; - сундуки с сокровищами; -
драгоценные камни; - королевская сокровищница; - магические эффекты.

Игровая сессия

Средняя продолжительность одной игры — 1–3 минуты.

Поражение

Игра заканчивается, если хотя бы один враг добирается до сокровищницы.

После окончания показываются: - итоговый счет; - количество собранных
Treasure Coins; - лучший рекорд.

Особенности проекта

• Простое управление одним пальцем. • Быстрые игровые сессии. •
Постепенное увеличение сложности. • Красочная мультяшная графика. •
Высокая реиграбельность.
